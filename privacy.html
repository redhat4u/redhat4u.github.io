소개개인정보처리방침서비스 약관

시행일: 2026년 9월 28일

1. 요약

USB Vault는 사용자의 PC에서만 동작하는 프로그램이며, 개발자가 운영하는 서버가 없습니다. USB Vault는 어떤 개인정보도 개발자에게 보내거나 수집하지 않습니다.

2. Google 사용자 데이터에 접근하는 방법

사용자가 Google Drive 동기화를 켜고 Google 로그인 화면에서 직접 허용한 경우에만, USB Vault는 Google OAuth 2.0을 통해 다음 권한 하나를 요청합니다.

  • https://www.googleapis.com/auth/drive.file — USB Vault가 만든 파일과 폴더에만 접근하는 권한입니다. 사용자의 Drive에 있는 다른 파일은 보거나, 읽거나, 바꾸거나, 지울 수 없습니다.

사용자의 Google 비밀번호는 USB Vault가 알 수 없으며, 로그인은 Google의 공식 로그인 페이지에서 이루어집니다.

3. Google 사용자 데이터를 사용하는 방법

  • USB Vault는 사용자의 암호화된 보관함 파일을 사용자 본인의 Google Drive에 올리고, 내려받고, 바꾸고, 휴지통으로 옮기는 데에만 이 권한을 사용합니다.
  • Drive에 올라가는 파일은 USB Vault가 사용자의 PC에서 미리 암호화한 것입니다. 파일 내용과 파일 이름 모두 암호화되어 있어, Google과 개발자를 포함한 누구도 내용을 알 수 없습니다.
  • Google 계정의 이메일 주소는 어떤 계정에 연결되었는지 사용자 화면에 보여 주는 용도로만 사용합니다.
  • Google 사용자 데이터를 광고, 분석, 프로필 작성, 인공지능 학습 등 다른 목적으로 사용하지 않습니다.

4. Google 사용자 데이터를 저장하는 방법

  • 로그인 후 Google이 발급하는 접근 토큰과 갱신 토큰은 사용자의 USB(또는 사용자가 정한 위치)에만 저장되며, 사용자의 보관함 암호로 암호화됩니다.
  • 개발자나 제3자의 서버로 전송되거나 저장되지 않습니다.

5. Google 사용자 데이터의 공유

USB Vault는 Google 사용자 데이터를 누구와도 공유, 판매, 전송하지 않습니다. 데이터는 사용자의 PC와 사용자 본인의 Google Drive 사이에서만 오갑니다.

6. 데이터 삭제와 접근 해제

  • USB Vault의 설정에서 Google Drive 연결을 해제하면 저장된 토큰이 삭제되고 Google에 토큰 무효화를 요청합니다.
  • 언제든지 Google 계정 → 서드 파티 앱 및 서비스에서 USB Vault의 접근 권한을 직접 삭제할 수 있습니다.
  • Drive에 올라간 파일은 사용자가 Google Drive에서 직접 지울 수 있습니다.

7. Google API 서비스 사용자 데이터 정책 준수

USB Vault가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구 사항 포함)을 따릅니다.

Privacy Policy (English)

Effective date: September 28, 2026

Summary

USB Vault runs entirely on the user's PC. The developer operates no servers and collects no personal information.

Access to Google user data

Only when the user enables Google Drive sync and grants consent on Google's sign-in page, USB Vault requests a single scope, https://www.googleapis.com/auth/drive.file, which limits access to files and folders created by USB Vault. USB Vault cannot see, read, modify, or delete any other files in the user's Drive. USB Vault never sees the user's Google password.

Use of Google user data

The scope is used solely to upload, download, update, and trash the user's encrypted vault files in the user's own Google Drive. Files are encrypted on the user's PC before upload (both contents and file names), so neither Google nor the developer can read them. The account email address is only displayed to the user to show which account is connected. Google user data is not used for advertising, analytics, profiling, or training AI/ML models.

Storage

OAuth tokens are stored only on the user's USB drive (or a location chosen by the user), encrypted with the user's vault password. They are never sent to the developer or any third party.

Sharing

USB Vault does not share, sell, or transfer Google user data to anyone. Data moves only between the user's PC and the user's own Google Drive.

Deletion and revocation

Disconnecting Google Drive in USB Vault's settings deletes the stored tokens and asks Google to revoke them. Users can also remove access at any time at Google Account → Third-party apps & services, and can delete uploaded files directly in Google Drive.

Limited Use

USB Vault's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
