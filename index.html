USB Vault

소개개인정보처리방침서비스 약관

USB Vault는 무엇인가요?

USB Vault는 USB 메모리에 넣어 다니는 Windows용 개인 암호화 보관함 프로그램입니다. 파일의 내용과 이름을 모두 암호화하여, 암호를 모르는 사람은 USB를 가져가도 파일을 볼 수 없습니다. 설치 없이 USB 안의 실행 파일 하나로 동작합니다.

주요 기능

  • 파일 내용과 이름 암호화 (XChaCha20-Poly1305, Argon2id)
  • 보관함을 드라이브(예: V:)로 연결해 일반 드라이브처럼 사용
  • 보안 화면 암호 입력, 가상 키보드, 자동 잠금
  • Google Drive 동기화: 암호화된 보관함 파일을 사용자의 Google Drive에 백업하고 여러 PC에서 맞춤

Google Drive 사용에 대해

USB Vault는 사용자가 직접 로그인하고 허용한 경우에만 Google Drive를 사용합니다. 권한은 drive.file로, USB Vault가 만든 파일에만 접근하며 Drive의 다른 파일은 보거나 바꿀 수 없습니다. Drive에는 이미 암호화된 파일만 올라가므로 Google을 포함한 누구도 내용과 파일 이름을 알 수 없습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

About USB Vault

USB Vault is a portable, personal encrypted vault for Windows that runs from a USB drive. It encrypts both file contents and file names, so nobody can read the files without the password.

Optionally, the user can sign in with Google to back up and synchronize the already-encrypted vault files to their own Google Drive. USB Vault requests only the drive.file scope, which limits access to files created by USB Vault itself. See the Privacy Policy and Terms of Service.
